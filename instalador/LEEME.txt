===============================================================
   pastepad 3.0.0 — instalacion
===============================================================

DOS FORMAS. Elige una:

   A)  instalar.bat          <- recomendada
       Se instala, arranca con Windows y sale en el menu inicio.

   B)  portable\pastepad-portable.exe
       Un solo archivo de 69 MB. Lo llevas en un pendrive y lo
       ejecutas donde sea. No instala nada ni arranca con Windows.

Eso es todo. No pide administrador, no toca Archivos de programa
y no cambia nada del sistema salvo una linea en el registro para
que arranque con Windows.


---------------------------------------------------------------
QUE HACE EL INSTALADOR
---------------------------------------------------------------

1. Copia el programa a:
      %LOCALAPPDATA%\pastepad

2. Lo registra para que arranque con Windows, en:
      HKCU\Software\Microsoft\Windows\CurrentVersion\Run

3. Crea un acceso directo en el menu inicio.

Se instala ahi y no en "Archivos de programa" a proposito:
pastepad guarda sus datos junto al ejecutable, y en Archivos de
programa Windows bloquea la escritura sin avisar. El programa
arrancaria pero no podria guardar nada.


---------------------------------------------------------------
"NO SE ENCUENTRA PYTHON311.DLL"
---------------------------------------------------------------

Si sale ese error es que copiaste pastepad.exe SOLO, sin la carpeta
_internal que va a su lado. Ahi dentro esta el interprete de Python
entero: el programa no necesita que tengas Python instalado, pero si
necesita esa carpeta.

Dos soluciones:

   - Copia la carpeta completa, no solo el .exe.
   - O usa la version portable, que lleva todo dentro de un unico
     archivo y no se puede romper de esa forma.

Comprobado: el ejecutable arranca en una maquina sin Python y sin
Python en el PATH.


---------------------------------------------------------------
COMO SE USA
---------------------------------------------------------------

   Ctrl + Shift + V        abre el panel junto al raton
   Escribe                 filtra
   Enter                   pega
   Esc o clic fuera        cierra

El panel no sale en la barra de tareas: vive del atajo.


---------------------------------------------------------------
COMO CERRARLO
---------------------------------------------------------------

Con el boton X del panel solo se esconde, que es lo que quieres
el 99% de las veces. Para cerrarlo del todo:

   Administrador de tareas
      Ctrl+Shift+Esc  ->  pestania Procesos  ->  pastepad
      -> clic derecho -> Finalizar tarea

   Consola
      taskkill /IM pastepad.exe /F

   Comprobar si esta corriendo
      tasklist /FI "IMAGENAME eq pastepad.exe"


---------------------------------------------------------------
WINDOWS DEFENDER Y SMARTSCREEN
---------------------------------------------------------------

Es muy probable que la primera vez salga:

   "Windows protegio su PC"

Para continuar:  Mas informacion  ->  Ejecutar de todas formas

IMPORTANTE, para que no te lleves una idea equivocada:

La licencia MIT y ser codigo abierto NO evitan este aviso.
SmartScreen no mira la licencia ni el codigo fuente. Solo mira
dos cosas:

   1. Si el ejecutable esta firmado con un certificado
   2. Cuanta gente lo ha descargado sin problemas

Como este binario no esta firmado, empieza con reputacion cero.
Ademas, al no estar firmado, la reputacion NO se hereda entre
versiones: cada compilacion nueva vuelve a empezar de cero.

Firmar con un certificado que te hagas tu mismo (autofirmado) NO
sirve para esto: Windows no confia en un certificado que no venga de
una autoridad reconocida, y el aviso sale igual. Solo vale para que
alguien pueda comprobar que el archivo no fue alterado, o para que
una empresa lo apruebe en sus equipos.

Que si funciona, de menos a mas esfuerzo:

   - Aceptar el aviso. Es un clic, una vez.
   - Publicar en GitHub Releases con el hash SHA256 a la vista,
     para que cualquiera pueda comprobar que el binario sale del
     codigo publicado.
   - Comprar un certificado de firma de codigo (unos 200-400 USD
     al anio). Reduce el aviso pero no lo elimina de inmediato:
     el certificado tambien tiene que ganar reputacion.
   - Publicar en la Microsoft Store. Es la unica via que lo quita
     del todo, porque Microsoft firma la app con su certificado.

Los certificados EV ya NO dan reputacion instantanea; eso dejo
de funcionar hace anios. Pagar el sobreprecio de un EV solo para
evitar SmartScreen ya no tiene sentido.


---------------------------------------------------------------
DESINSTALAR
---------------------------------------------------------------

Doble clic en:  desinstalar.bat

Pregunta antes de tocar tus textos guardados. Si dices que no,
deja una copia de snippets.json e historial.json en el escritorio
antes de borrar el programa.
